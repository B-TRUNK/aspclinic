Web App:
--------
- create a blazor/maui app -> dotnet new maui-blazor-web -o MauiBlazorWeb -I {INTERACTIVITY}
    with Server option

- changed netclinic.Web.csproj net version to 10

- run app -> dotnet watch(hotreload)/run(ordinary) --project netclinic.Web

Mobile App:
-----------
- emulator -avd maui_android(your successfully running emulator) 

- run -> cd netclinic
dotnet build -t:Run -f net10.0-android
